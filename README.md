# CellCraft

A Minecraft mod for cellular automata and crafting, supporting both Forge and Fabric loaders.

## Features

- Multi-loader support (Fabric & Forge)
- Example Cell Block item
- Built with Architectury API for cross-platform compatibility

## Building

To build the mod, run:

```bash
./gradlew build
```

The compiled mod jars will be located in:
- `fabric/build/libs/` - Fabric version
- `forge/build/libs/` - Forge version

## Requirements

- Java 17 or higher
- Minecraft 1.20.1
